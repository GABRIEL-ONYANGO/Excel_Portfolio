# Excel_Portfolio

A collection of practical data analysis projects built in **Microsoft Excel**.  
This portfolio demonstrates skills in data cleaning, analysis, and visualization, showcasing Excel’s power for business intelligence and reporting.

---

## Features
- Data cleaning and preparation (formatting, deduplication, text standardization)
- Analytical techniques (pivot tables, lookups, conditional functions)
- Visualization (charts, histograms, sparklines, dashboards)
- End-to-end workflows for real-world datasets

---

## Project Highlights
1. **Sales Dashboard** – Interactive dashboard with KPIs and trend analysis  
2. **Customer Analysis** – Segmentation using pivot tables and lookup functions  
3. **Financial Model** – Scenario analysis and forecasting with Excel formulas  
4. **Data Cleaning Toolkit** – Examples of text, date, and duplicate handling  

---

## Purpose
This repository serves as a portfolio to demonstrate Excel proficiency in:
- Business intelligence reporting  
- Data-driven decision making  
- Visualization and storytelling with data  

---

## Tools Used
- Microsoft Excel (Pivot Tables, Charts, Functions, Power Query)
- Sample datasets (CSV/Excel files)

---

## How to Use
1. Clone or download the repository.  
2. Open the Excel files in Microsoft Excel.  
3. Explore dashboards, formulas, and workflows.
