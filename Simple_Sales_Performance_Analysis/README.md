# Excel Sales Performance Analysis

## Project Overview

This project demonstrates how Microsoft Excel can be used to clean,
analyze, and visualize sales data. I transformed a raw sales dataset,
performed statistical and outlier analysis, summarized sales performance
using PivotTables, and brought the key findings together in a dashboard.

The project is designed to demonstrate practical Excel skills for data
analysis and business reporting.

## Objectives

-   Prepare raw sales data for analysis.
-   Explore price and quantity using descriptive statistics.
-   Investigate potential outliers in prices across managers' entries.
-   Analyze sales quantity and revenue across products, payment methods,
    and months.
-   Present key sales metrics in a dashboard.

## Tools and Excel Features

-   Microsoft Excel
-   Data cleaning and transformation
-   Descriptive statistical analysis
-   Outlier analysis
-   PivotTables and percentage-of-total analysis
-   Dashboard reporting and data visualization

## Workflow

### 1. Data Transformation and Cleaning

I prepared the dataset for analysis by: - Trimming extra spaces from the
**Manager** column to improve consistency. - Rounding values in the
**Quantity** column up to whole numbers. - Creating a **Revenue** field
to support sales and revenue analysis.

### 2. Statistical Analysis

I performed statistical analysis on the **Price** and **Quantity**
columns to better understand the distribution and characteristics of
these variables.

### 3. Outlier Analysis

I investigated potential outliers in the **Price** column, examining
entries by manager to identify unusually high or low price values that
may warrant further review.

> Outliers are signals for investigation, not automatically errors.
> Their business context should be checked before any values are removed
> or changed.

### 4. PivotTable Analysis

I used PivotTables to summarize the data and answer key sales questions,
including:

-   **Quantity Sold:** How much product was sold?
-   **Revenue Earned:** What was the total revenue?
-   **Revenue by Product:** Which products contributed to revenue?
-   **Revenue by Payment Method:** What percentage of revenue came from
    each payment method?
-   **Revenue by Month:** How did revenue vary over time?

### 5. Dashboard

Finally, I created an Excel dashboard to bring the analysis together in
a visual summary. The dashboard provides a convenient view of the sales
metrics and breakdowns explored in the project.
